합창단 출석부 · 웹앱 2.0.0

운영자가 한 번만 하는
Google 연결 설정

웹앱 코드는 준비되었습니다. 현재 Google 연결 정보가 등록되지 않아 로그인을 시작할 수 없습니다. 아래 설정은 프로그램 운영자만 합니다. 합창단 담당자는 로그인하고 시트를 선택하면 됩니다.

1. Google Cloud 프로젝트 준비

Google Cloud Console 열기에서 운영자 계정으로 로그인하고 출석부용 프로젝트를 만들거나 선택합니다. 모든 설정을 같은 프로젝트에서 진행하세요.

프로젝트의 프로젝트 번호를 확인합니다. 문자로 된 프로젝트 ID가 아니라 숫자 번호입니다.

API 라이브러리에서 다음 세 가지를 사용 설정합니다.

  • Google Sheets API
  • Google Drive API
  • Google Picker API

2. Google 로그인 동의 화면

Google Auth Platform에서 앱 이름을 합창단 출석부로 등록하고 사용자 지원 이메일과 개발자 연락처를 입력합니다. 외부 사용자가 쓸 수 있도록 대상은 External을 선택합니다.

요청 권한은 아래 범위만 등록합니다. 전체 Drive 접근 권한은 추가하지 않습니다.

openid
https://www.googleapis.com/auth/userinfo.email
https://www.googleapis.com/auth/userinfo.profile
https://www.googleapis.com/auth/drive.file

초기 시험은 테스트 사용자로 운영자 계정을 추가합니다. 일반 배포 전에는 게시 상태를 Production으로 변경하고 Google이 요구하는 기본 앱/브랜드 검증을 완료합니다. 앱 주소 변경만으로 Google의 미확인 앱 경고가 사라지는 것은 아닙니다.

앱 홈페이지: https://seoyoungdal.github.io/choir-attendance/app/
개인정보 안내: https://seoyoungdal.github.io/choir-attendance/app/privacy.html
이용 안내: https://seoyoungdal.github.io/choir-attendance/app/terms.html

Google이 도메인 소유권 확인을 요구하면 검증 가능한 운영자 소유 도메인으로 배포 주소를 연결하고, 홈페이지·개인정보·Origin 주소도 함께 바꿔야 합니다.

3. OAuth 웹 클라이언트 만들기

클라이언트 만들기에서 유형을 웹 애플리케이션으로 선택합니다. 승인된 JavaScript 원본에 아래 값을 등록합니다. /app/ 경로와 마지막 슬래시를 붙이지 않습니다.

https://seoyoungdal.github.io

이 앱은 브라우저 토큰 방식이므로 서버 리디렉션 주소와 Client secret을 사용하지 않습니다. 생성한 클라이언트 ID(끝이 .apps.googleusercontent.com)를 확인합니다.

4. 브라우저용 API 키 만들기

사용자 인증 정보에서 API 키를 만들고 애플리케이션 제한을 웹사이트(HTTP referrer)로 설정합니다.

https://seoyoungdal.github.io/*
https://docs.google.com/*

API 제한에서는 Google Picker API와 Google Drive API만 허용합니다. Google Sheets REST 요청은 OAuth 토큰을 사용합니다.

5. 세 가지 연결 정보 적용

운영자가 확인한 아래 세 가지를 웹앱 설정에 등록하고 다시 배포합니다. 각 합창단 담당자는 이 작업을 하지 않습니다.

  • OAuth 웹 클라이언트 ID
  • 제한이 적용된 브라우저 API 키
  • 동일 Cloud 프로젝트의 숫자 프로젝트 번호

개발 설정 파일은 dist/app/config.json입니다. 세 가지 공개 식별값만 넣습니다. Google 비밀번호, OAuth Client secret, 서비스 계정 키 파일은 넣지 않습니다.

6. 기존 자료로 최종 확인

  1. 새 웹앱 열기 → Google로 로그인합니다.
  2. 기존·공유 시트 연결 → Google 시트 선택에서 기존 출석부 시트를 선택합니다. 등록된 합창단 이름이 자동으로 입력됩니다.
  3. 단원·연습·출석 자료가 그대로 보이는지 확인합니다.
  4. 시험용 별도 시트에서 출석 저장과 다른 편집자의 접속을 확인합니다.
  5. 일반 시작 주소에서도 이 웹앱이 바로 열립니다. 새 주소로 사용자에게 안내합니다.

Google 비밀번호는 Google 로그인 창에만 입력합니다. 출석부에는 별도 아이디·비밀번호와 운영자 사용 승인이 없습니다. 최초 시트 접근 동의는 Google이 요구하는 절차입니다.
